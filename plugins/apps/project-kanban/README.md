# 🗂️ Project Kanban

一个基于 PawApp 框架开发的**按项目组织的多智能体看板**：为项目设定简介和成员智能体，把项目拆成任务指派给不同成员，多个智能体各自排队、并行推进同一个项目。

需求文档：[`docs/requirements.md`](docs/requirements.md)。

## ✨ 特性

- 🗂️ **项目为主维度** - 项目包含简介（会作为上下文发给智能体）、成员和任务；支持归档 / 取消归档 / 删除
- 👥 **项目成员** - 任务只能指派给项目成员；移除成员时自动处理其任务并提示影响数量
- 🔑 **可读的任务编号** - `WEB-12` 形式（项目代号 + 项目内递增编号，编号永不复用）
- 🤖 **按智能体排队调度** - 每个智能体同一时间只运行一个任务（跨所有项目），排队按入队时间先进先出；事件唤醒，空闲智能体 1 秒内开始
- 📊 **实时输出** - SSE 实时显示工具调用与消息，迟到的查看者也能看到同样的回放
- ✅ **工具调用授权** - 在卡片上批准 / 拒绝本项目运行中任务的授权请求
- 🧰 **智能体工具** - 成员智能体可查询自己参与的项目和项目内任务（含队友的结果摘要）
- 🌐 **中英双语** - 自动跟随 QwenPaw 的语言设置；其他语言回退为英文

## 🚀 快速开始

### 安装

通过 QwenPaw 应用中心安装：

1. 打开 QwenPaw 应用中心
2. 搜索 "Project Kanban"
3. 点击安装

### 使用

1. **创建项目** - 在项目列表点击「+ 新建项目」，填写名称、代号（默认按名称生成）、简介，选择成员智能体
2. **拆分任务** - 进入项目，点击「待规划」列标题的 `+` 新建任务，指派给某个成员（可勾选「立即排队」）
3. **排队 / 运行** - 点击「运行」：成员空闲则立即开始，忙碌则进入其队列（按钮显示「排队」）
4. **查看与授权** - 展开运行中卡片查看实时输出；需要授权的工具调用直接在卡片上批准或拒绝
5. **验收** - 成功的任务进入「审核中」，可查看结果后「标记完成」「重新运行」或「重新打开」
6. **管理成员** - 点击顶部「成员」打开成员抽屉，添加或移除成员

## 📖 看板列说明

| 列名 | 说明 |
|------|------|
| 待规划 | 规划中，不会被调度；运行失败或被停止的任务也回到这里（带错误信息，不自动重试） |
| 等待调度 | 已指派成员，在该成员的队列中等待（卡片显示「排队中 #n」，成员在其他项目忙碌时会注明） |
| 进行中 | 成员正在执行；只能通过「运行」进入、通过「停止」离开 |
| 审核中 | 运行成功，等待验收 |
| 已完成 | 已验收 |

拖拽卡片（按住卡片顶部的编号行）可在列之间移动；不允许的移动会在本地直接提示，不会发请求。拖到「进行中」等同于点击「运行」。

## 👥 成员与调度规则

- 指派只设置负责人，不会自动排队（规划阶段可以先指派很多任务）
- 一个智能体同一时间只运行一个任务，**跨所有项目**；不同智能体并行
- 每个智能体的队列跨项目按入队时间先进先出；重启时被中断的任务排在最前面
- 归档项目只读：任务保持原状态但不调度；取消归档后按原入队时间恢复
- 移除成员：其「等待调度」任务退回「待规划」并取消指派，其「待规划」任务取消指派；「审核中/已完成」保留原负责人。成员正在本项目运行任务时不能移除
- 只有已归档的项目可以删除（删除会同时删除其任务及会话文件）

## 🎨 视图

- **项目列表** - 进行中 / 已归档两个标签；卡片显示代号、简介、成员、各状态数量、运行数和待授权数
- **看板视图** - 5 列看板（默认）
- **成员视图** - 每个成员一条泳道，显示其在本项目的任务，以及「空闲 / 运行中 WEB-1 / 忙于 <其他项目>」和跨项目队列长度

## 🧰 智能体工具

| 工具 | 说明 |
|------|------|
| `project_kanban_list_my_projects` | 列出调用者所属的项目（简介、成员、计数、自己的未完成任务） |
| `project_kanban_list_project_issues` | 列出某个项目（id 或代号）的任务，含队友结果摘要 |
| `project_kanban_get_issue` | 按 id 或 `WEB-12` 获取任务详情及完整结果摘要 |
| `project_kanban_list_my_issues` | 列出调用者在所有项目中的任务 |

工具均为只读（治理类型 `internal`），只返回调用者是成员的项目；非成员一律返回 `NOT_A_MEMBER`。

## 💾 数据与运行说明

- 数据保存在应用目录下的 `data/board.json`（单文件，原子写入；锁文件 `data/.board.lock`）
- ⚠️ **重新安装 / 升级应用会替换整个应用目录**，请先备份 `data/board.json`
- 每个任务使用独立会话 `pawapp:project-kanban:issue:<id>`，每次运行前清空；该会话不会出现在控制台的聊天列表中
- 不支持两个 `qwenpaw app` 实例共用同一个工作目录运行本应用：文件读写是安全的，但每个实例启动时都会把“没有本进程任务在跑”的进行中任务视为中断并重新排队

## 🔐 安全说明

- 实时输出使用 `EventSource`，它无法设置请求头，因此认证 token 通过查询参数 `?token=` 传递。若前面有 nginx，访问日志可能记录该 token。建议对 `/api/project-kanban/projects/*/issues/*/stream` 关闭访问日志（或不记录查询串），例如：

  ```nginx
  location ~ ^/api/project-kanban/projects/[^/]+/issues/[^/]+/stream$ {
      access_log off;
      proxy_pass http://127.0.0.1:<port>;
      proxy_buffering off;
  }
  ```

  否则需明确接受这一风险。
- 智能体输出和用户文本经过加固的 Markdown 渲染：先转义 `& < > " '`，只为 `http:` / `https:` 生成链接
- 授权接口只处理属于本项目运行中任务的请求

## ✅ 手动测试清单

UI 没有自动化测试框架，发布前按以下清单在中英文下各走一遍：

- [ ] 创建项目（代号自动生成 / 手动填写 / 重复代号报错），添加成员
- [ ] 新建任务（仅成员可选；勾选「立即排队」）、编辑、删除
- [ ] 运行任务，展开查看实时输出；运行结束后查看结果
- [ ] 两个不同成员的任务同时运行
- [ ] 同一成员在两个项目中各有任务：第二个显示「排队中 #1 · X 忙于 <项目>」，前一个结束后自动开始
- [ ] 停止运行中的任务（回到待规划，显示已停止）
- [ ] 需要授权的工具调用：批准 / 拒绝
- [ ] 运行失败的任务回到待规划并显示错误，不自动重试
- [ ] 移除成员的确认文案数量正确；成员在本项目运行时不能移除
- [ ] 归档（运行中时被拒绝）→ 只读横幅、控件禁用 → 取消归档 → 删除
- [ ] 切换 QwenPaw 语言，界面立即切换

## 🧪 开发与测试

```bash
cd /path/to/QwenPaw
uv run pytest plugins/apps/project-kanban/backend/tests -q
```

后端测试覆盖存储事务、状态机全表、成员 / 生命周期规则、错误码、调度（跨项目忙碌、FIFO、孤儿恢复、唤醒延迟）、授权匹配与工具权限；`test_ui.py` 用 Node 在沙箱中加载 `ui/index.js`，检查路由注册、中英文键一致、Markdown 加固和本地状态校验。
